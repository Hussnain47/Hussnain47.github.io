AI-assisted translation, with an editor in control.

A multilingual email workflow connecting a React editor, GraphQL, versioned content, and guarded AI translation.

ContextProduct engineering · Khoros Community
My roleFull-stack implementation and design decisions
TechnologyReact / TypeScript / Java / GraphQL / LLMs
Draft→Translate→Review

Conceptual overview · not a production topology

The problem

Community administrators needed to manage email templates across languages without breaking dynamic variables, formatting, or the existing delivery behavior. Asking a language model to preserve an entire HTML document was not a sufficient correctness strategy.

My contribution

I worked on the multilingual template model, locale-aware resolution, GraphQL operations, and the Aurora editor workflow, then added AI-assisted translation. The work included the editor translation action, undo behavior, and a fallback-model chain in AI Settings.

Separate language from version

A locale lives within a template version. Publishing a version publishes its language variants together. Review status is a separate dimension: approving a translation makes it eligible for delivery but does not publish the version. This preserves both human review and atomic version publishing.

Constrain what the model can change

The translator sends prose spans to the model, keeping document structure outside the model’s output. Deterministic guards validate markup and placeholders. This responds to observed failures in which a model changed formatting or translated a dynamic variable. Translation produces content for review; it does not bypass the review gate.

Preserve the delivery contract

An unavailable or unapproved locale falls through to the existing translated Handlebars template, rather than silently serving the English database variant. Manual authoring remains available when AI is unconfigured. The model fallback chain adds another recovery option without changing the editorial workflow.

Validation and outcome

The implementation connected the AI action to the editor, corrected an undo bug that left the canvas out of sync, and added a model fallback chain. The earlier backend phase passed 94 orchestration tests, including checks around locale resolution and the review gate.

What I learned

Make AI a replaceable source of draft content. Put the durable guarantees—structure, variables, review, and publishing—in ordinary application code.
